# ארכיון הקו הבוחן

הנתונים ההיסטוריים הכבדים של [הקו בזמן](https://kavbochan.app/line-history/) — תבניות המסלולים
(`early-patterns`) ורישומי התחנות (`early-stops`) מהארכיונים של 2003–2018. האתר קורא אותם מכאן:
`https://transit-freak.github.io/kav-bochan-archive/early-patterns/…`

- הייבוא ההיסטורי הסתיים (11.2026), ושתי התיקיות נמחקו מהריפו הראשי
  [kav-bochan](https://github.com/Transit-Freak/kav-bochan). **העותק כאן הוא המקור היחיד שלהן** — לא למחוק.
- `sync.yml` מעתיק מהריפו הראשי רק את קבצי הנסיעות התפעוליות של קו פח (`deadhead`), שם הם נשמרים 21 יום בלבד.
- `verify.yml` בודק אחרי כל סנכרון שהאתר עונה (קוד 200 וכותרת CORS).
