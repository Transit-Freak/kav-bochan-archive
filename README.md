# ארכיון הקו הבוחן

עותק של הנתונים ההיסטוריים הכבדים של [הקו בזמן](https://kavbochan.app/line-history/) — תבניות המסלולים
(`early-patterns`) ורישומי התחנות (`early-stops`) מהארכיונים של 2003–2018 — כדי שהאתר הראשי לא יעלה אותם
מחדש בכל עדכון.

- המקור הוא הריפו [kav-bochan](https://github.com/Transit-Freak/kav-bochan), תחת `line-history/data/`.
  `sync.yml` מעתיק משם כל שעה (אחרי הייבוא השעתי של הארכיון) ומפרסם את הכול ב-GitHub Pages:
  `https://transit-freak.github.io/kav-bochan-archive/early-patterns/…`
- אין לערוך כאן קבצים ידנית — כל ריצה מסנכרנת מול המקור (כולל מחיקות).
